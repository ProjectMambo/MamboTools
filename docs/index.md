# MamboTools

MamboTools is the central terminal manager for Project Mambo repositories. It turns the official catalog into clear, guarded install, fast-forward update, and local removal actions.

::button{label="Source code" href="https://github.com/ProjectMambo/MamboTools" variant="secondary" external=true}

## Current release

Version `0.1.0` is the first functional MVP. It manages a built-in catalog, follows XDG paths, renders through MamboUI, and protects every destructive boundary.
